# ReviewLens — Scope Specification

## IN SCOPE (MVP)

- **Paste Code Interface:** Allow users to paste TypeScript or JavaScript code snippets.
- **Built-in Demo Example:** Preloaded realistic TypeScript snippet (`OrderService.ts`) with 4 intentional defects (unsafe undefined access, weak typing, mixed persistence responsibilities, unhandled async rejection).
- **AI Code Review:** Senior engineer + mentor perspective identifying 3–5 high-value issues.
- **Structured Findings:** JSON-validated schema with categorized findings (`bug`, `security`, `maintainability`, `type-safety`, `testing`, `performance`, `readability`) and severities (`critical`, `high`, `medium`, `low`).
- **Finding Details:**
  - Problem description & affected code preview.
  - **"Why Does This Matter?"** — educational rationale explaining real-world consequences.
  - **Engineering Principle** — underlying software engineering law or design pattern.
  - **Suggested Improvement** — actionable guidance with code diff.
- **"Challenge Me" Interaction:**
  - Interactive 3-choice quiz per finding generated by the review.
  - Client-side deterministic evaluation (instant, no extra LLM round-trip).
  - Immediate feedback with educational explanation.
- **Skill Score Progression:**
  - Gamified score tracking across categories: Bug Detection, Security, Maintainability, Type Safety, Testing.
  - Deterministic score calculation (+3 points on correct answer, capped at 100).
  - LocalStorage persistence and score hydration.
- **Dual Review Provider Architecture:**
  - First-class `MockReviewProvider` for 100% reliable hackathon demos and offline use.
  - `LLMReviewProvider` for live AI analysis with runtime Zod validation.
  - Visual indicator of active provider.
- **UX States:**
  - Domain-specific animated loading state ("Checking correctness...", "Checking type safety...", etc.).
  - Empty, invalid, and network error handling states.

---

## OUT OF SCOPE

Explicitly excluded from this Proof of Concept:

- User authentication and authorization.
- GitHub / GitLab / Bitbucket API and PR integration.
- Full repository analysis / multi-file AST indexing.
- Application Knowledge Graph (AKG).
- RAG (Retrieval-Augmented Generation) and vector databases.
- Multi-agent production backends.
- Billing, subscription, and pricing systems.
- Teams, organizations, and multi-user sync.
- Cloud databases and remote persistence.
- CI/CD bot integrations.
